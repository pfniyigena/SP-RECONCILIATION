Customer Deposit Matching

FIFO-allocates unmatched card transactions against each customer's deposits, oldest deposit first, until each deposit's total amount is reached. Safe to re-run — only touches transactions that haven't been matched yet.

Card Transaction / Invoice Matching

Per stamp machine (SDC), matches unprocessed card transactions against that SDC's unprocessed card-paid invoices by date and amount (with several rounding tolerances). A matched transaction gets the invoice's stamp data and is marked successful; either way it's marked processed so it isn't retried automatically.

Stamp Lookup (SQL Server)

Resolves stampData for every CustomerDeposit that doesn't have it yet, by looking each one up against the external SQL Server Stamp table via its sapReference. A deposit with no match yet in that table is retried on every run, not skipped after one miss. Runs on stamp.pull.cron.expression.
